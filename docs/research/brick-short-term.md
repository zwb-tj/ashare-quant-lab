## 0. 一句话结论

**「短期砖型图」不是一个独立指标，而是一个指标公式的正式名称**——它在参考实现里的
docstring 中直接写作「通达信标准公式 - **短期砖型图指标 v2026**」【有据：见第 6 节来源】。
它的"短期"体现在三处：**参数短**（4 / 6 窗口）、**周期短**（日线级）、
以及**搭配的交易纪律短**（买入后 3 天不涨就走，最多拿 4 天）。

因此追问"短期砖型图与普通砖型图有何不同"，答案是：**同一套公式**；
"短期"是这个名字的一部分，也是它被使用的语境（短线节奏），而不是另一组参数。

## 1. 「短期砖型图」是什么

### 1.1 官方定位：它是**第二层（买入模块）的五种玩法之一**

Z哥把交易体系分为四层颜色模块【有据：`knowledge/trading-core.md` 3.0 节】：

| 层 | 颜色 | 作用 | 内容 |
| --- | --- | --- | --- |
| 第一层 | 🟥 红 | **择时** | 活跃市值 4% 多头 / -2.3% 空头 |
| 第二层 | 🟦 蓝 | **买入** | B1 / B2 / B3 / 单针下 30 / **砖形图** |
| 第三层 | 🟧 橙 | **判断依据**（给买点做验证） | 关键 K、倍量柱、四块砖、长阴短柱… |
| 第四层 | 🟨 黄 | **应对**（买入后的防线） | 止损 → 放飞 → S1 → 滴滴 → 破白线 → 破黄线 → 死叉 |

**关键含义**：砖型图**既是买点**（第二层），"四块砖法则"**又是过滤器**（第三层）。
这两个角色容易被混为一谈，实际用法不同（见第 4、5 节）。

### 1.2 选池子的前提

第 2 步「选池子和节奏」明确要求：**只看黄线之上、白线之上、有砖形图节奏的票**
【有据：`knowledge/trading-core.md` 12 步流程第 2 步】。

### 1.3 与 MACD 共振（被称为「A 股胜率最高战法」）

| MACD 区间 | 砖型图操作 |
| --- | --- |
| 多头区间 + 红柱 | 放心找红砖上车，"插上了就踏实，插上就开始数砖" |
| 多头区间 + 绿柱 | 谨慎；最多 1/10 仓位试，必须设止损 |
| 空头区间 | **看都不要看**，再漂亮的红砖都是诱多 |

【有据：`knowledge/indicators.md` 第 100–107 行】

## 2. 完整公式与逐行解读

### 2.1 通达信公式原文

```pascal
VAR1A := (HHV(H,4) - C) / (HHV(H,4) - LLV(L,4)) * 100 - 90;
VAR2A := SMA(VAR1A, 4, 1) + 100;
VAR3A := (C - LLV(L,4)) / (HHV(H,4) - LLV(L,4)) * 100;
VAR4A := SMA(VAR3A, 6, 1);
VAR5A := SMA(VAR4A, 6, 1) + 100;
VAR6A := VAR5A - VAR2A;
砖型图 := IF(VAR6A > 4, VAR6A - 4, 0);
```

【有据：`indicators_extra.py:132-145`（本仓库）与参考实现 `brick.py:9-16` 完全一致】

### 2.2 逐行解读（每个中间量在**测什么**）

| 变量 | 公式 | 在测什么 |
| --- | --- | --- |
| `VAR1A` | `(HHV(H,4) - C) / (HHV(H,4) - LLV(L,4)) * 100 - 90` | **收盘价在近 4 日区间中的"离顶距离"**。收盘越靠近 4 日最高价 → 值越小（甚至为负）；越靠近最低价 → 越大。它是"上方压力/超买程度"的度量 |
| `VAR2A` | `SMA(VAR1A, 4, 1) + 100` | 把上面的"离顶距离"做 **4 日递推平滑**（通达信 `SMA(X,N,M)` 是 `Y = (X*M + Y'*(N-M))/N`，不是简单均线），再抬到 100 附近作为基准 |
| `VAR3A` | `(C - LLV(L,4)) / (HHV(H,4) - LLV(L,4)) * 100` | **收盘价在近 4 日区间中的"离底距离"**（0~100）。它是"下方支撑/超卖程度"的度量，与 `VAR1A` 恰好互补（两者之和 ≈ 10，因 `VAR1A` 减了 90） |
| `VAR4A` | `SMA(VAR3A, 6, 1)` | "离底距离"的 **6 日递推平滑** |
| `VAR5A` | `SMA(VAR4A, 6, 1) + 100` | **二次平滑**（对 `VAR4A` 再做一次 6 日递推平滑），即"离底动量"的慢线 |
| `VAR6A` | `VAR5A - VAR2A` | **慢速离底动量 − 慢速离顶程度**。当股价从底部走强，"离底"上升而"离顶"下降，两者差扩大 → 值变大 |
| `砖型图` | `IF(VAR6A > 4, VAR6A - 4, 0)` | **阈值截断**：只有 `VAR6A > 4` 才计值，并减去 4 作为基准偏移；否则归 0 |

**一句话理解**：砖型图是一个**把"价格在 4 日区间内的相对位置"做双重平滑后的动量差**，
再用 4 作门槛过滤噪声。它不是价格、不是成交量，而是**位置动量的合成量**。

### 2.3 为什么要双重平滑

`VAR3A`（离底距离）会在价格剧烈波动时抖动；先 `SMA(...,6,1)` 得到 `VAR4A` 降噪，
再平滑一次得到 `VAR5A`，这样砖型图的变化更接近"趋势"而不是"单日噪音"。
这解释了为什么砖型图看起来比 K 线"慢半拍"——**平滑是刻意设计的**。

## 3. 红砖 / 绿砖 / 连续砖数

### 3.1 判定口径

| 状态 | 判定 | 含义 |
| --- | --- | --- |
| **红砖** | 今日砖值 **≥** 昨日砖值 | 动量在上升 |
| **绿砖** | 今日砖值 **<** 昨日砖值 | 动量在下降 |

【有据：参考实现 `brick.py:79-81`、`brick.py:299-306`；本仓库 `indicators_extra.py:167-169` 用 `>` / `<` 严格比较】

### 3.2 两个实现的一个细节差异【重要】

- 参考实现（Z 哥体系）：**`>=` 计入红砖**（砖值不变算红）
- 本仓库 `brick_chart()`：**`>` 才计入红砖**（砖值不变既不算红也不算绿，红绿都为 0）

这个差异在"砖值恰好持平"时会产生**不同的连续砖数**。实测中持平较少，但不是不会发生
（尤其价格横盘时）。**若要严格对齐 Z 哥口径，应把本仓库改为 `>=`。**

### 3.3 连续砖数（第 N 块砖）

**`red_streak` / `green_streak`**：从最新一根往前数，同色连续多少根。
本仓库 `brick_streaks()` 已实现；砖值不变时**保持前值**（既不新增也不清零）
【有据：`indicators_extra.py:196-200`】。

### 3.4 全市场红/绿砖持续天数分布（实测）

全市场（沪深主板+创业+科创）2025-09~2026-08 的统计【有据：`BRICK_MINING_REPORT.md`】：

| 持续天数 | 红砖段占比% | 绿砖段占比% |
| --- | --- | --- |
| 1 天 | 32.7 | 31.2 |
| 2 天 | 18.2 | 18.0 |
| 3 天 | 13.5 | 15.1 |
| 4 天 | 13.0 | 13.3 |
| 5 天 | 9.2 | 8.3 |
| 6 天 | 5.6 | 5.5 |
| 7 天 | 3.7 | 3.6 |
| 8 天 | 2.0 | 2.2 |
| ≥5 天 | 22.7 | 22.3 |

- 红砖段**平均持续 3.05 天**，绿砖段**平均 3.11 天**；中位约 1 天。
- **红砖恰好或超过 4 天的占比 = 35.6%**——与"四块砖"的说法吻合。

**这段数字很重要**：它说明"数砖"不是玄学——**约 1/3 的红砖段会走到第 4 块**，
所以"第 4 块减仓"这条规则有实际触发频率。

## 4. 四块砖法则（核心用法）

### 4.1 法则原文

> 源于威尔斯·威尔德 Delta 理论，**A 股短期每 4 天一个情绪循环**。

【有据：`knowledge/trading-core.md` 3.2 节】

| 规则 | 内容 |
| --- | --- |
| **红砖上涨循环** | 第 1 块红砖确认入场 → 持有 → **第 4 块红砖走完至少减仓一半** |
| **绿砖下跌循环** | 绿砖出现**绝不抄底** → 先数满 4 块 → **翻红且不创新低**才轻仓试错 |
| **第 4 砖加速定律** | 若第 4 块红砖向上加速，则下跌周期里第 4 块绿砖也会向下加速 |
| **白线之上绿砖** | 优先看作**技术性洗盘**，只要没**有效跌破白线**就别慌；但绿砖必须**贴近白线**，脱离成本区过远的是获利盘出逃 |
| **时间纪律** | **买入后 3 天不涨就走，最多拿 4 天** |

### 4.2 「4 天」的来源

源于 **威尔斯·威尔德（Welles Wilder）的 Delta 理论**——该理论认为市场存在
短的（4 天）、中的、长的（Delta 转折）周期序列【有据：同上；Delta 理论为公开理论】。

### 4.3 与"情绪循环"的呼应

参考实现里的规则注释【有据：`brick.py:271-275`】：

1. 红砖数满 4 块 → **减仓至少一半**
2. 红砖翻绿 → **立刻止损**
3. 绿砖下跌 → **绝不抄底，先数 4 块**
4. 买入后 3 天不涨 → **止损**（"DSZ 铁律"）

## 5. 买点、减仓与止损

### 5.1 买点：第 1~2 块红砖是买点区

参考实现 `detect_red_brick_start(max_streak=2)` 的规则映射写得最清楚：
**「第 1、2 块红砖是买点区，第 4 块必减半，翻绿即止损」**
【有据：`brick.py:241-246`】。

### 5.2 「反包」买点（绿转红）

`detect_fanbao_min_green(min_green=2)` 定义了一个更严格的买点【有据：`brick.py:163-193`】：

- 昨日绿砖（相对前日）→ 今日红砖（相对昨日）；
- **今日砖值必须越过昨日绿砖实体的 2/3 位**；
- **且翻红前连续绿砖数 g ≥ 2**。

**为什么要求 g ≥ 2**：下面第 5.4 节的回测数据显示，"只绿 1 天就反包"在开波段里
**反而亏钱**（-2.35%），是噪音。

### 5.3 减仓与止损（四块砖体系）

`detect_four_brick_system()` 实现的判定【有据：`brick.py:263-361`】：

| 当前状态 | 动作 |
| --- | --- |
| 红砖翻绿（刚由红转绿） | **止损**：立刻走 |
| 红砖连续 ≥ 4 块 | **减仓**：至少减一半 |
| 绿砖连续（任意块数） | **禁止抄底**：先数满 4 块 |
| 绿砖连续 ≥ 4 块 | 跌势可能接近尾声，但**仍禁止抄底** |
| 红砖连续 < 4 块 | **持有** |

### 5.7 与 0AMV 波段的关系（重要，且反直觉）

【有据：`BRICK_MINING_REPORT.md` B 节】

| 0AMV 状态 | 样本日 | 红砖日占比 | 绿砖日占比 | 平均砖值 |
| --- | ---: | ---: | ---: | ---: |
| 开波段 | 563,845 | 46.5% | 53.5% | **83.48** |
| 关波段 | 681,597 | **52.2%** | 47.8% | 76.34 |

**反直觉之处**：开波段的**红砖日占比反而更低**（46.5% vs 52.2%）。
原因：关波段常有"急跌后的红砖反抽"。
但开波段的**砖值水平更高**（均值 83.5 vs 76.3）——**动量大、趋势质量高**。

**结论**：砖型买点应看**开波段 + 红砖质量/刚启动**，而不是只看"是不是红砖"。
这解释了为什么回测里砖型买点**只在开波段有效**。

- 手工复算时我先写了普通 `dict` 存放结果（无 `.iloc`），导致比较逻辑本身报 `False`——
  **那是我脚本的 bug，不是公式差异**；改为 `DataFrame` 后差值为 0。此处如实记录，避免误读。

   默认关闭以保持现有行为不变；
4. **保留 4/6 参数**——"短期"不是靠改参数实现的，改参数会偏离原公式。

## 8. 常见误用与陷阱

| 陷阱 | 说明 | 依据 |
| --- | --- | --- |
| **把"红砖"当成买入信号** | 红砖只表示"动量上升"，**红砖 ≥4 后收益转负**（量价V3 第 4 块 -10.97%） | `BRICK_MINING_REPORT.md` C 节 |
| **只看红砖不看波段** | 关波段常出现"急跌后的红砖反抽"，红砖日占比甚至更高（52.2%） | `BRICK_MINING_REPORT.md` B 节 |
| **单绿一天就反包** | 开波段里 -2.35%，是噪音；必须 g ≥ 2 | `BRICK_CANDIDATES_REPORT.md` |
| **小样本当规律** | B3 + 红砖刚翻转 +15.31% 只有 **11 例** | 同上 |
| **空头区间看红砖** | "MACD 空头区间看都不要看，再漂亮的红砖都是诱多" | `knowledge/indicators.md:106` |
| **等数据不足** | 参考实现要求 ≥ 12 根 K 线才出砖值（4 窗口 + 6 平滑的双重预热） | `brick.py:17` |
| **停牌/涨跌停导致公式失真** | 停牌时 H=L=C，公式分母 `HHV-LLV` 可能为 0 | 本仓库用 `.replace(0.0, np.nan)` 兜住；参考实现直接给 `v3=50.0` **【推测：两者处理不同，需注意】** |
| **周期错配** | "做短线就盯 60 分钟，做波段就只看日线"；拿日线信号做 60 分钟必亏 | `knowledge/indicators.md:110` |
