## 0. 核心结论（先说结论）

1. **动态分组确实支持自然语言**，官方原文示例就是一句话：「MACD金叉，KDJ金叉，均线多头排列的股票」
   【官方】。所以"用一句话选股"这个用法是成立的。
2. **它背后是同花顺智能选股系统**，且**支持多重条件过滤**【官方】。
3. **它有一批"独门秘技"形态词**——官方明确列举：**金针探底、仙人指路、五线开花、空中加油、老鸭回头**
   【官方】。这意味着**形态类选股是靠内置的"形态名词"，而不是靠描述**。
4. **「砖型图」几乎可以肯定不在它的内置词表里**——它是 Z 哥体系/通达信自定义指标的叫法，
   官方列举的独门秘技里没有它，它也**不是同花顺的标准形态**。
   **【推断，需实测】**（见第 4 节与第 9 节）。
5. **因此，"用一句话让动态分组选出与砖型图完全相同的票"——我的判断是：做不到精确复现。**
   但这不代表没用：可以退而求其次，**用它听得懂的语义条件，去逼近砖型图选出的票的共同特征**。
   第 5、6 节给出可执行的替代方案。

## 1. 动态分组是什么

**官方定义**（同花顺官方页面原文要点）【官方】：

> 动态分组是基于**同花顺智能选股系统**，能够根据用户不同的需要，通过**数以万计的选股条件**
> 从股票市场挑选符合条件的股票。不同于市场上单一的选股方式，动态分组**支持多重条件过滤**。

要点：

| 项目 | 内容 | 来源 |
| --- | --- | --- |
| 本质 | 同花顺智能选股系统的一个入口 | 【官方】 |
| 条件规模 | "数以万计的选股条件" | 【官方】 |
| 条件组合 | 支持多重条件过滤 | 【官方】 |
| 与电脑版关系 | **电脑的"动态板块" = 手机的"动态分组"**，数据同步 | 【官方】 |
| 查看条件 | 在自选股列表可查看当前分组的**问句条件** | 【官方】 |

**"问句条件"这个说法很关键**：官方用"问句"来称呼你的输入，说明它本身就是一个
**自然语言查询接口**，这与"问财（iWenCai）"的定位一致。

> **它和"问财"是同一个东西吗？** —— 【推测】很可能是同一套引擎（同花顺智能选股系统）的不同入口。
> 依据：两者都接受中文自然语言并解析为量化条件；第三方工具 `iwencai-cli` 的说明里称
> 问财"支持用中文自然语言描述筛选条件（如"市盈率小于20"、"日线 MACD 金叉"等），后端自动解析为量化条件"
> 【有据：[iwencai-cli README](https://github.com/shaw-baobao/iwencai-cli)】。
> **但我没有找到官方声明"动态分组 = 问财"**，因此仅作推测。

## 3. 它能听懂什么（语义能力）

### 3.1 官方示例（原文照录）

| 类型 | 官方示例 |
| --- | --- |
| 技术指标组合 | 「MACD金叉，KDJ金叉，均线多头排列的股票」 |
| 基本面组合 | 「连续三年净利润增长大于10%，市盈率小于30的股票」 |
| 独门形态词 | 金针探底、仙人指路、五线开花、空中加油、老鸭回头 |

### 3.2 语法能力（来自问财资料，**动态分组大概率相同但未验证**）

问财的选股条件分两类【有据：[叩富网问答](https://licai.cofool.com/ask/qa_7575294.html)】：

1. **自然语言模式**：日常表述即可，例：「近10日成交额连续放大的沪深A股」；
2. **专业语法模式**：「字段 + 运算符 + 数值/条件」，运算符含 `>`、`<`、`=`，
   多条件用 **「且」/「或」** 连接。

示例（原文）：自然语言「市盈率小于20，市净率小于1.2，近1年股息率超过3%的沪深A股」；
专业语法「市盈率<20 且 市净率<1.2 且 股息率>3%」。

**可推断的能力清单**【有据，但需在你手机上验证】：

| 能力 | 支持情况 | 备注 |
| --- | --- | --- |
| 数值比较 | ✅ | `市盈率小于20` |
| 多条件 AND | ✅ | 用「，」或「且」 |
| 多条件 OR | ✅ | 用「或」 |
| 时间窗口 | ✅ | 「近10日」「连续三年」 |
| 技术指标 | ✅ | 「MACD金叉」「KDJ金叉」 |
| 均线关系 | ✅ | 「均线多头排列」 |
| 内置形态名词 | ✅ | 「金针探底」等 |
| 成交量/换手 | ✅ | 「成交额连续放大」 |
| 板块/市场范围 | ✅ | 「沪深A股」 |
| **自定义指标（如砖型图）** | ❌ **很可能不支持** | 见第 4 节 |

## 4. 关键问题：它认识「砖型图」吗

### 4.1 判断：**很可能不认识**

理由：

1. **官方列举的"独门秘技"里没有砖型图**——官方给了 5 个形态词
   （金针探底、仙人指路、五线开花、空中加油、老鸭回头），**均无砖型图**【官方】；
2. **砖型图不是同花顺标准指标**——它是通达信体系的自定义公式（见
   [砖型图研究](brick-short-term.md)），其公式含 `HHV/LLV/SMA` 递归平滑，
   属于**用户自定义指标**范畴；
3. **动态分组的条件来自"数以万计的选股条件"库**——库里的形态是大厂通用形态，
   不会收录某位博主体系里的自定义指标名。

**所以：输入「砖型图」或「红砖」，最可能的结果是：**
- 【推测】被当成无法识别的词而**忽略**；或
- 【推测】被模糊匹配到别的形态（更危险，因为你会误以为选对了）；
- 【未验证】也可能返回空结果。

**这三种情况我无法在不开你手机的情况下确定——所以这一条必须由你实测，见第 7 节。**

### 4.2 那"金针探底"这类词能不能代替

部分可以，但**不等于砖型图**：

| 内置形态词 | 与砖型图的关系 |
| --- | --- |
| 金针探底 | 是**单根 K 线**的下影线形态；砖型图是**动量指标**，不同维度 |
| 仙人指路 | 也是 K 线形态 |
| 五线开花 | 均线形态 |
| 空中加油 | 趋势中继形态（与 Z 哥"空中加油"同名，但定义未必一致） |
| 老鸭回头 | 均线/趋势形态 |

**关键**：这些是**形态词**，砖型图是**动量指标**。二者可以"同向"但不能等价。
用它们只能做到**特征近似**，做不到"相同的票"。

## 5. 用它能听懂的话描述砖型图

既然不能直呼其名，就要把砖型图的**语义**翻译成它能听懂的**可量化条件**。

### 5.1 砖型图的语义拆解（来自[砖型图研究](brick-short-term.md)）

砖型图 ≈ **把"价格在近 4 日区间内的相对位置"双重平滑后的动量差**。它的可观测语义是：

| 砖型图概念 | 可翻译成的动态分组条件 |
| --- | --- |
| 红砖（动量上升） | 股价上涨 / 收阳线 / 均线向上 |
| 绿砖（动量下降） | 股价下跌 / 收阴线 |
| **绿转红（反包买点）** | **今天上涨且昨天/前天是下跌** |
| 红砖第 1~2 块（买点区） | **连续上涨 1~2 天（不要超过 3 天）** |
| 红砖 ≥4（该减仓） | 连续上涨 ≥4 天 |
| 白线之上 + 黄线之上 | 股价在均线之上（如「股价在 20 日、60 日均线之上」） |
| 贴近白线 | 股价接近 20 日均线（如「股价距 20 日均线 3% 以内」） |
| 开波段（择时） | 这个**动态分组大概率无法表达**（需 0AMV 指标，见第 8 节） |

### 5.2 「红砖刚启动」的语义核心

砖型图的买点核心是**「动量刚由负转正」**，对应到可表达的语言是：

> **连续下跌若干天后，今天开始上涨**

这可以用「**N 天前下跌 且 今天上涨**」或「**昨天收阴 今天收阳**」来表达。
**这是最接近"绿转红反包"的一句。**

### 5.3 注意：无法表达的三个要素

以下三点是砖型图的核心，但**大概率无法用一句话表达**：

| 无法表达 | 原因 |
| --- | --- |
| **砖值本身**（如「砖值 > 100」） | 需要自定义指标计算（双重 SMA 递推 + 阈值 4） |
| **连续砖数**（如「红砖第 2 块」） | 需要先算出砖值序列再数连续段 |
| **0AMV 开波段** | 0AMV 是自定义活跃市值指标，非标准指标 |

## 6. 候选提示词方案

下面给出**可直接复制**的候选句子，按"离砖型图多远"排序。
**每一条都必须用第 7 节的方法验证后才能采信。**

### 6.1 第一组：直接试探（用来确认它认不认识砖型图）

```
砖型图
红砖
砖型图选股
```

**用途**：这是**诊断性**输入，不是选股语句。看它返回什么，就能判断它认不认识这个词。
若返回空或无关结果 → 确认不支持（预期如此）。

### 6.2 第二组：逼近「红砖刚启动（第 1~2 块）」（最有希望的一组）

```
连续下跌3天后今天上涨的股票
昨天收阴今天收阳的沪深A股
近5日跌幅超过5%今天放量上涨的股票
股价在20日均线之上且今天放量上涨的股票
连续上涨不超过2天的股票
```

**对应砖型图**：红砖第 1~2 块（买点区）。

### 6.3 第三组：逼近「绿转红反包」

```
昨天收阴线今天收阳线且放量的股票
前天和昨天都下跌今天上涨的股票
近3日先跌后涨的股票
```

**对应砖型图**：反包买点（`g≥2` 口径，即**前面至少绿 2 天**——
所以「前天和昨天都下跌」比「昨天收阴」更接近）。

### 6.4 第四组：加入「白线之上 + 贴近」（对齐 Z 哥的选池前提）

```
股价在20日和60日均线之上且今天上涨的股票
股价距20日均线不超过3%且今天放量上涨的股票
MACD金叉且股价在20日均线之上的股票
```

**对应**：Z 哥"只看黄线之上、白线之上"的前提
（黄线 ≈ 多均线均值，白线 ≈ `EMA(EMA(C,10),10)`；
动态分组里可用「均线多头排列」「股价在 N 日均线之上」近似）。

### 6.5 第五组：排除项（对齐砖型图的风险控制）

```
排除连续涨停3天以上的股票
排除近5日涨幅超过20%的股票
非ST的沪深A股
```

**对应**：「红砖 ≥4 收益转负」——**不追高**是砖型图的重要纪律
（实测：量价V3 在红砖第 4 块 -10.97%）。

### 6.6 组合示例（把上面拼成一句话）

```
昨天收阴今天收阳且放量，股价在20日均线之上，非ST的沪深A股
```

```
连续下跌3天后今天上涨，股价在60日均线之上，排除近5日涨幅超过15%的股票
```

## 7. 怎么验证选对了

**这一步不能省**——否则你不知道选出的是不是砖型图的票。

### 7.1 用你的真实选股日志做对照（推荐）

你手上有 **59 个 Z 哥选股日志文件**（`picks_archive/picks_*.json`）
以及本仓库已有的回测工具。建议流程：

1. **挑一个已知日期**：从 `picks_archive` 里选一个有明确砖型买点记录的日期；
2. **看当天 Z 哥实际选了哪些票**（作为"正确答案"）；
3. **把第 6 节的候选句子输入动态分组**，看它选出的票；
4. **比对重叠率**：`重叠数 / 动态分组选出数`。

本仓库已有 `picks-backtest` 与 `confirm-eval` 可以辅助处理这些日志。

### 7.2 更严格的验证：用本仓库算砖型图

因为本仓库的 `brick_chart()` 已被**实测验证与官方公式逐列一致（误差 0）**
（见[砖型图研究](brick-short-term.md) 第 6 节），所以你可以：

1. 对动态分组选出的票，**用 `aqlab` 算出它当天的砖型状态**；
2. 检查这些票是否**恰好命中砖型买点**（红砖第 1~2 块 / 绿转红反包）；
3. **命中率高** → 这句话有效；**命中率低** → 它选的其实是别的东西。

```bash
# 示例：对某批票检查砖型状态
python -c "
from aqlab.indicators_extra import brick_chart, brick_streaks
# 读取该票日线 -> 算砖型 -> 看是否处于红砖第1~2块
"
```

### 7.3 最小验证清单（建议你做的事）

| # | 动作 | 判断 |
| --- | --- | --- |
| 1 | 输入「砖型图」 | 返回空/无关 → 确认不支持（预期） |

## 8. 为什么"用一句话精确复现砖型图"很可能做不到

我必须诚实说明这一点，因为你说过"之前很多 AI 都没办法完全明白这项功能"。

**技术上，砖型图无法被压缩成一句自然语言**，原因有三：

1. **它是数值型自定义指标，不是形态**
   砖型图 = `IF(VAR6A>4, VAR6A-4, 0)`，其中 `VAR6A` 由 **两轮 `SMA` 递推平滑**得到。
   自然语言选股引擎的形态库是"命名形态"（金针探底之类），**没有"用户自定义递归指标"这一类**。

2. **"连续砖数"是路径依赖量**
   "红砖第 2 块"需要先算出历史砖值序列、再判断连续段。自然语言条件大多描述
   **当前状态**（"股价在均线之上"），难以表达"从某状态起连续第 N 根"。

3. **它的择时前提（0AMV）也是自定义指标**
   砖型图买点**只在开波段有效**（实测：反包买点在开波 +2.15%、关波 -1.05%），
   而 0AMV 同样是自定义指标，**动态分组大概率没有**。

**因此**：
- ✅ **能做**：用一句话逼近砖型图的**若干可观测特征**（涨跌节奏 + 均线位置 + 放量），
  得到一个"砖型图票池的高重叠子集"；
- ❌ **做不到**：让动态分组输出与 `brick_chart()` **完全一致的票集**。

**如果实测发现某句话重叠率很高（比如 >70%），那已经是很好的结果**——
但那仍是"近似"，不是"等价"。**建议不要把近似当成等价用于决策。**
