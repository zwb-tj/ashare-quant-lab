# Alpha 因子研究：从 44 个公式到 3 个候选

> 这份文档是整条因子研究链的**自述**：每一步做什么、砍掉多少、为什么。所有数字都来自本仓库
> 可复现的命令，`output/` 下有对应的 CSV。写作原则是**不美化**——被否掉的假设与被证实的结论同等重要。

## 一、起点：为什么自己实现 Alpha101 子集

- **只实现能算的**：Alpha101 中依赖**行业分类、市值、指数成分**（`IndNeutralize` / `cap` / `Sector`）的公式，
  本机没有对应数据，因此**实现 44 个、显式跳过 22 个**，每个跳过项在 `alpha101.SKIPPED` 里写明缺什么。
  **不用近似值冒充缺失数据**。
- **代码来源干净**：公式是公开的（WorldQuant 的 *101 Formulaic Alphas* 与公开复现），本项目按公式
  **重新实现**（含 `ts_rank` / `decay_linear` / `cross_rank` / `scale` 等算子层），没有拷贝第三方代码，
  仓库保持 MIT。
- **算子方向**：面板统一为 `dates × symbols`，**时序算子沿列**、**截面算子沿行**。这是因子实现最容易静默出错的地方，
  测试用可解析的构造数据分别验证（`ts_argmax` 的"距最新一根的位置"、`cross_rank` 的逐日独立排名）。

数据：全市场 **5,424 只**，日线 2024-06 ~ 2026-09（**556 个交易日**，其中因子在 260 根预热后从 2025-06-30 起有值，
可用截面 **112 个**，按 5 日步长取样）。

## 二、第一步：IC 有多大（全样本）

逐截面 Spearman 秩相关（因子值 vs 未来收益），重叠加权修正 t 值（`t / sqrt(ceil(horizon/step))`）。
共 **111 个 (因子 × 持有期) 组合**（37 个因子 × 3 个持有期）。

| 口径 | 显著组合数 |
| --- | ---: |
| 不校正（p ≤ 0.05） | **41** |
| **BH-FDR** | **35** |
| **Bonferroni** | **28** |
| 期望假阳性（不校正时） | **5.55** |

**为什么必须先做这一步**：111 次检验在 5% 水平下**期望就有 5.55 个假阳性**。
不做校正就报"41 个显著"，等于把噪声当发现。校正实现是自己写的（Bonferroni + Benjamini-Hochberg，
p 值来自 `math.erfc`，不引入 scipy），并用三种方式交叉验证，其中与 `statsmodels.multipletests(fdr_bh)`
的**逐元素对照最大差 1.1e-16**。

## 三、第二步：样本外还成立吗（单次切分）

时间轴前后各半（切分日 **2025-07-24**），**用样本内选、用样本外验**（顺序不能反）。

| 结果 | 数量 |
| --- | ---: |
| 样本内 BH 校正后显著 | **16** |
| **样本外仍显著且同向** | **11 / 16** |
| 样本外反向 | 3 |

**最扎心的一条**：样本内最强的两个因子**样本外直接失效** ——
`alpha_008`（样本内 t=**4.90** → 样本外 **-0.54**）、`alpha_001`（4.84 → -0.35）。
这是"在样本内挑最强"的经典陷阱。

## 四、第三步：多折验证（单次切分不够）

单次 50/50 可能恰好切在有利时段，因此改成**连续 4 折 walk-forward**（训练段扩张窗口、方向只由训练段 IC 符号决定、
两段都要 |t| > 2）。折切在**因子真正有值**的区间上（否则靠前折的训练段落进 260 根预热期内、被整折跳过——
真实数据上 5 折只剩 2 折，这是跑出来才发现的）。

| 口径 | 数量 |
| --- | ---: |
| 至少被某折训练段选中 | 23 |
| 被选中 ≥ 2 折 | 16 |
| **稳健（≥2 折被选中且存活率 ≥60%）** | **12** |

稳健因子（前 6）：`alpha_013` / `alpha_016` / `alpha_050` / `alpha_015`（均 5 日持有，4 折中存活 3 折，
测试段 IC +0.036 ~ +0.061、t 2.27 ~ 4.66）；`alpha_044` / `alpha_026`（3 折存活 2 折）。

**逐折矩阵暴露的关键事实：折 4（测试段 2026-03-27 ~ 2026-06-25）被选中的 20 个组合，存活 0 个**；
其它三折合计存活 36 个。→ 这些因子**存在整段失效的窗口**，而单次切分完全看不到这一点。

## 五、第四步：扣成本后还剩多少（IC ≠ 可交易）

IC 是**收盘价对收盘价、整条截面**的秩相关，不等于"买了能赚"。组合层必须：
**次日开盘入场**（信号来自前一日收盘）、**方向只由样本内 IC 符号决定**、**成本按实际换手收**。

33 个 (因子 × 持有期) 组合（`top_n=20`，持有 1/5/20 日，双边 20bps）：

| 口径 | 数量 |
| --- | ---: |
| 毛超额为正 | 19 |
| 净超额（扣 20bps）为正 | 17 |
| **净超额 t > 2** | **3** |
| 平均换手 | **0.904** |
| 盈亏平衡成本中位数 | **23.4 bps** |

净超额 t > 2 的三个组合：

| 因子 | 持有期 | 净超额 | t | 换手 | 盈亏平衡成本 |
| --- | ---: | ---: | ---: | ---: | ---: |
| alpha_006 | 20 日 | +2.00% | 2.57 | 0.996 | 220.9 bps |
| alpha_016 | 1 日 | +0.32% | 3.09 | 0.641 | 70.4 bps |
| alpha_013 | 1 日 | +0.23% | 2.22 | 0.627 | 57.3 bps |

**换手 0.90 意味着每期几乎换掉全部持仓**（一年约 50 期 × 18bps ≈ 9% 成本）。
这解释了为什么 19 个毛超额为正的组合里只有 3 个净超额 t > 2。

## 六、第五步：失效能不能解释（状态依赖性）

把 IC 按**当日市场状态**分组（等权指数动量 / 横截面离散度 / 0AMV 波段，状态已滞后一天）。

折 4 窗口的状态确实异常：**动量低占 50%**（其它时段 23%）、**离散高占 67%**（其它时段 25%）、
**开波段占 75%**（其它时段 45%）；折 4 平均 IC **+0.0041 / 正 IC 占比 49.2%**，
其它时段 **+0.0559 / 86.6%**。

**两个假设被数据否掉**（如实记录）：

1. ~~"高离散导致失效"~~ → **否**。离散度最高档的 IC 反而**最强**：
   `alpha_013` 离散高 +0.064 vs 离散中 +0.053；`alpha_016` +0.070 vs +0.055。
2. ~~"动量低导致失效"~~ → **否**。动量低档整体优于动量高档（`alpha_026` +0.061 vs +0.035），
   而折 4 正好落在动量最低档却接近零。

**唯一干净的发现**：0AMV 波段有区分度 —— 10 个因子里 **7 个**在**关波段**下的 IC 高于开波段
（`alpha_050` 关波段 +0.063 / t=7.94 vs 开波段 +0.038 / t=3.90；`alpha_026` +0.068 / 4.82 vs +0.029 / 2.01）。
但 `alpha_003` / `alpha_006` / `alpha_012` **方向相反**，所以这**不是普适规律**。

→ **折 4 的失效没有被机制解释**，如实记为未解决，而不是硬凑一个说法。

## 七、结论

**证据链**：`41 个显著` → `35（BH 校正）` → `11（单次样本外）` → `12（多折稳健）` → `3（扣成本后 t>2）`

1. **IC 层面的显著性与"能交易"之间隔着三道关口**：多重比较、样本外、交易成本。每道都会砍掉大量候选。
2. **扣成本后只剩 3 个候选**（持有期 1~20 日，净超额 +0.23% ~ +2.00%），且它们的**持有期与样本量都不足以称为可靠策略**
   （20 日持有一组只有 14 期；1 日持有一组换手 0.63）。
3. **因子存在整段失效窗口**（折 4 全灭），且**尚未找到解释** —— 这是本项目最重要的一条负面结论：
   不能因为"平均 IC 显著"就认为因子长期可用。

## 八、边界（必须与结论同读）

- **单一市场、单一时期**：只有 2024-06 ~ 2026-09 的 A 股数据（可用截面 112 个），没有跨市场验证；
- **分档用全样本分位**：状态分析里的档位边界用到了未来信息（真实交易只能事后知道），
  因此第三节之后的状态结论是**解释性的，不是可交易信号**；
- **每档样本很薄**：0AMV 两组各 29/30 个截面，折 4 只有 12 个截面；20 日持有的组合只有 14 期；
- **未建模**：涨跌停不可成交、停牌、冲击成本、融券约束；因子值为前复权日线；
- **因子值口径**：`vwap` 缺失时用典型价近似（见 `alpha101.build_panel`）；
- **幸存者偏差**：标的池是"当前仍在上市"的集合。

## 九、复现

```bash
python scripts/fetch_universe_daily.py                       # 全市场日线（约 5 分钟）

# 1) 全样本 IC + 多重比较校正 + 单次样本外
aqlab factor-ic --alpha101 --data-dir data/universe/daily \
    --horizons 1,5,20 --step 5 --min-history 260 --min-symbols 200 --out output

# 2) 多折 walk-forward（见 scripts/ 或下方 Python 调用）
python -c "from aqlab.walk_forward_folds import FoldConfig, run_walk_forward; ..."

# 3) 组合层成本检验
aqlab factor-backtest --data-dir data/universe/daily --top-n 10 --forward 20 --cost-bps 20 --out output

pytest -q
```

产物：`output/alpha101_ic_real/`（校正与样本内外）、`output/alpha101_ic/`（多折、成本、状态）。
